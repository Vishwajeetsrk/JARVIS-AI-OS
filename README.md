# ⚡ JARVIS APEX-UI — Flagship Operating Platform

The animated **3D Autonomous-Agent Orb + Reasoning-Graph Constellation** platform for **JARVIS AI OS**, architected and developed by **Vishwajeet (@Vishwajeetsrk)**.

---

## 🌟 Key Capabilities

1. **3D Particle Orb Core (`ApexCore3D` & `ApexHeroOrb`)**: Real-time WebGL particle core reacting to autonomous states (`idle` → `listening` → `thinking` → `speaking`).
2. **18-Node Reasoning Constellation (`ReasoningWeb`)**: High-contrast circuit traces and glowing agent nodes for Chief of Staff, Memory, Strategist, Researcher, Finance, Engineering, Design, Sales, Ops, and more.
3. **Interactive Agent Cockpit (`AgentCockpit.tsx`)**: Click any agent node to launch a focused AI cockpit with real-time prompt streaming, one-click action triggers, model selector, and speech synthesis.
4. **PC Device & Application Bridge (`/api/os`)**: 1-click launcher for VS Code, Windows Terminal, Chrome, File Explorer, Slack, Discord, and PowerShell command execution.
5. **Real-Time Hybrid Voice Pipeline (`VoicePipeline.tsx`)**: Continuous speech-to-text with Web Speech API and Groq Whisper, hands-free action execution, and neural speech synthesis.
6. **Universal Projects Hub (`ProjectLauncher.tsx`)**: Instant access to all active workspace projects (JARVIS AI OS, Learnify, StaffU CRM, Voice Cloner, Algorithmic Art, MCP Protocol Hub).
