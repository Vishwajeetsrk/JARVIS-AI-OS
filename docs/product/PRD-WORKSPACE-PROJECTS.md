## 3. Key Functional Requirements

1. **Zero-Mock Policy**: All placeholder titles (StaffU CRM, Voice Cloner, Algorithmic Art, MCP Protocol Hub) are permanently removed.
2. **Elimination of Broken Ports**: All links pointing to `http://localhost:8080/console` are replaced with real application routes, GitHub repositories, and working local workspace triggers.
3. **Integrated Workspace Console**: Users can run live PowerShell/CLI commands, check git status, test build health, and inspect file trees directly within the Projects Hub.
4. **1-Click Workspace Launch**: Direct integration with VS Code (`code .`) and local directory opening (`explorer .`).
