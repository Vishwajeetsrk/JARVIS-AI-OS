## Departmental Responsibilities & Communication

1. **Executive Steering**: `ceo-agent` -> Validates idea via Clarity Framework and issues Golden Flow route.
2. **Planning & Breakdown**: `team-agent` -> Converts decision into task breakdown and maintains `status.md`.
3. **Engineering & Build**: `saas-builder`, `ai-agent`, `ml-agent` -> Implement features adhering to TRD specs and security baselines.
4. **Design & Brand System**: `design-agent` -> Enforces CSS design tokens, HSL color palettes, and responsive glassmorphism layouts.
5. **Quality & Security Audit**: `test-agent` -> Performs mandatory hard-stop QA audit before deployment.
6. **DevOps & Monitoring**: `devops-agent` -> Manages Vercel deploys, n8n webhook alerts, and rollback points.
7. **Knowledge & Self-Learning**: `memory-agent` -> Reads global memory before execution and logs lessons learned after completion.
