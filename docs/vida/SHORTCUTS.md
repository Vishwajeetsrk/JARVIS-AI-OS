# ⌨️ Vida AI OS — Keyboard Shortcuts Reference

## Global Shortcuts

| Shortcut (Windows) | Shortcut (macOS) | Action |
| :--- | :--- | :--- |
| `Ctrl + Space` | `Cmd + Space` | Toggle Vida Command Console |
| `Ctrl + Shift + Space` | `Cmd + Shift + Space` | Toggle 3D Floating Avatar Companion |
| `Ctrl + Shift + V` | `Cmd + Shift + V` | Analyze & Rescue Clipboard Text |
| `Ctrl + Shift + S` | `Cmd + Shift + S` | Capture & Inspect Active Screen |
| `Ctrl + Shift + M` | `Cmd + Shift + M` | Start/Stop Voice Dialogue (Wake: "Hey Nia") |
| `Ctrl + Shift + Esc` | `Cmd + Shift + Esc` | Emergency Stop for Active Agent Task |

## In-Console Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Enter` | Send message to AI / Agent |
| `Shift + Enter` | Insert newline |
| `Esc` | Cancel speech / Close modal dialog |
| `Ctrl / Cmd + N` | Start New Conversation Thread |
| `Ctrl / Cmd + K` | Focus Global Command Search |
| `Ctrl / Cmd + L` | Focus Message Input Area |
| `Ctrl / Cmd + C` | Copy Selected Rescued Content |
| `Up Arrow` | Edit previous user message |
