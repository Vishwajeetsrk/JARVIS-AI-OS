# 🛠️ Vida AI OS — Tool Suite & SOTA Engines

Vida integrates 7 production-grade, type-safe modular tools:

## 1. Reply Savior (Reply Rescue)
- **Purpose:** Contextual message responder for emails, Slack, and LinkedIn.
- **Tones:** Professional, Friendly, Concise, Persuasive, Apologetic, Direct.
- **Features:** Editable output textarea, point-by-point breakdown, 1-click clipboard copy.

## 2. Prompt Savior (Prompt Rescue)
- **Purpose:** Upgrades fuzzy queries into structured, production-ready prompts.
- **Output:** Objective, Context, Constraints, Assumptions, Deliverables.
- **Features:** Categories (Coding, Architecture, Writing, General), 1-click copy.

## 3. Resume Savior (Resume Rescue)
- **Purpose:** Generates ATS-optimized resume summaries and bullet points.
- **Guarantee:** Strict authenticity guarantee — never hallucinates unprovided career facts.
- **Export:** 1-click `.md` Markdown file download.

## 4. Workspace Janitor (Workspace Cleanup)
- **Purpose:** Safe cleanup of stale downloads, duplicate files, and temp logs.
- **Safety:** Restricted to user-approved paths, dry-run simulation mode, and Windows Recycle Bin staging.

## 5. Daily Wrap (Daily Review)
- **Purpose:** End-of-day summary of accomplishments, commits, and blockers.
- **Output:** Accomplishments, in-progress items, blockers, and tomorrow's top 5 priorities.

## 6. Market & Investment Research
- **Purpose:** Comprehensive intelligence briefings.
- **Standards:** Distinguishes verified facts, market estimates, working assumptions, and strategic risks.
- **Compliance:** Includes non-financial advice disclaimer and labeled citations.

## 7. Deck & Sheet Builder
- **Purpose:** Native presentation and spreadsheet generation.
- **Output:**
  - 16:9 dark-mode executive slide decks (`.pptx`).
  - Structured data audit workbooks (`.xlsx`).
