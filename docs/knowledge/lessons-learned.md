# Lessons Learned & 7-Step Learning Pipeline

## The 7-Step Learning Pipeline
1. **Mistake**: Catch incident during execution or test-agent audit.
2. **Lesson**: Analyze root cause.
3. **Rule**: Formulate actionable prevention rule.
4. **Pattern**: Codify fix pattern in `global-pattern-library.md`.
5. **Best Practice**: Update `docs/knowledge/knowledge-base.md`.
6. **Template**: Create reusable boilerplate template.
7. **Automation**: Enforce check automatically via Mastra TS / `test-agent`.
