# Product Overview

## What is Jarvis AI OS?

Jarvis AI OS is a persistent-memory AI Operating System with 30+ specialized agents,
150+ design systems, and integration with 68+ open-source repos.

## Target Users

- Solo developers and small teams
- AI/ML engineers building agent systems
- Product managers needing automated workflows

## Key Features

- Multi-agent orchestration via Mastra
- Cross-session memory recall (pgvector)
- Spec-driven development
- Automated hooks and workflows
- Voice assistant integration
- Local-first AI with cloud fallback

## Business Objectives

- Zero recurring cost ($0 baseline)
- Production-grade reliability
- Extensible agent architecture
- Cross-platform (Web, Desktop, CLI, Mobile PWA)
